# 需求说明书：阳光小助手（客服回复助手）

| 项目 | 内容 |
| --- | --- |
| 需求编号 | REQ-015 |
| 提出方 | 甲方（店主） |
| 负责人 | 开发 |
| 优先级 | P1 |
| 类型 | 新功能（经营管理全局插件）＋ 经营总览页头调整 |
| 状态 | 阶段 1（界面）开发完成（待客户查看）；阶段 2 待客户提供问答整理 |
| 关联文档 | REQ-014（市场分析）；经营总览 |

## 1. 需求来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈 | 微信个人号和群聊无法接入官方智能客服；希望在管理系统里放一个小机器人，客服把客户问题复制粘贴进去，机器人给出回复，客服再复制回微信 |
| 客户提供的参考方案 | 先整理高频问答和客服语气、建立知识库，价格、库存、到期日实时查询系统，不先训练模型；第一版做内部"客服回复工作台"，记录客服对回答的处理 |
| 客户提供的界面参考 | 深色玻璃输入框，紫到橙渐变发光边框；发送后移到页面右侧成为整列问答栏（类似浏览器侧边 AI 栏）；提问以发光气泡显示 |
| 客户确认 | 入口在每个页面标题栏右上角，文字"问问阳光小助手"；问答栏宽度和输入框高度可拖动；切换页面不影响问答；不能与页面内容叠放；不要麦克风；先做界面，问答整理随后提供 |
| 客户确认 | 经营总览去掉"刷新今日数据"按钮（系统自动刷新）；"经营日期"移到"库存更新、POS 最近成功同步"同一行并靠右 |

## 2. 现状

| 项目 | 现状 | 问题 |
| --- | --- | --- |
| 页面标题栏右侧 | 只有经营总览有"经营日期"和"刷新今日数据"，数据中心有"刷新状态"，其余页面为空 | 各页面不统一，没有放置全局工具的位置 |
| 刷新今日数据 | 点击后触发一次 POS 同步再重新加载；页面本身不会定时重新加载 | 正式环境 POS 已由门店电脑定时同步，按钮多余；页面打开后数据不会自己更新 |
| 右侧"阳光小助手"悬浮图标 | 只用于显示本页说明 | 与客服回复无关，保留；问答栏打开时暂时隐藏，避免与问答栏重叠 |
| 库存经营、数据中心 | 个别宽表格会把整个内容区撑宽 | 标题栏右侧的入口会被挤出可见区域 |

## 3. 需求内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 入口 | 经营管理每个页面标题栏右上角显示"问问阳光小助手"发光按钮（阳光图标＋文字），手机端只显示图标 |
| F2 | 输入框 | 点击入口，从按钮位置缓慢浮现深色玻璃输入框：紫到橙渐变边框缓慢流动、发光呼吸；框内有"常用问题"和发送按钮；不设麦克风和附件。Enter 发送，Shift+Enter 换行，Esc 收起 |
| F3 | 问答栏 | 发送后输入框平滑移到页面右侧，展开为整列问答栏：顶部为名称、新对话、收起；中间为问答区，提问以发光气泡显示；底部为输入框。每条回复下方有"复制回复、重新生成、转人工" |
| F4 | 可调整 | 拖动问答栏左边缘调宽度（320–720 像素；宽屏时保证页面内容区至少约 860 像素，抽屉时不超过窗口一半）；拖动输入框上边缘调高度（72–320 像素）；也可用键盘方向键调整。尺寸在本浏览器记住 |
| F5 | 不叠放、不丢失 | 宽屏（1360 像素及以上）时问答栏作为页面右侧一列，左侧导航收为图标栏（悬停显示名称），页面内容区相应收窄，不覆盖页面；页面排版按内容区自身宽度调整（经营总览指标卡改两行三列、商品分析筛选栏折行、本周进货表格商品名折行、数据中心不再被撑宽）。较窄屏幕改为右侧抽屉并加遮罩，手机为全屏。问答栏属于经营管理外层框架，切换页面问答保留；收起后再打开恢复原对话；刷新浏览器后在本次会话内恢复 |
| F6 | 阶段 1 不编造回复 | 问答库未接入前，回复位置显示"问答库整理中，暂未接入"，回复操作按钮不可用；不使用任何模拟答案 |
| F7 | 经营总览页头 | 去掉"刷新今日数据"；"经营日期"移到"库存更新、POS 最近成功同步、查看数据检查"同一行，整行靠右；查看过去日期时保留"回到今天"。查看今天时，页面在窗口可见期间每 5 分钟自动重新加载一次（只读本地数据库，不触发 POS 同步） |
| F8 | 阶段 2（待问答整理后开发） | 问答库（固定信息、商品资料、必须转人工的规则）；价格、库存、到期日实时查询本系统；高风险问题（孕妇、儿童、疾病、不良反应、投诉、退款争议）直接提示转人工；记录客服对每条回复的处理（直接采用、修改后采用、拒绝、转人工）。接口与数据表另行设计，届时补充 |

## 4. 范围与限制

- 本需求只在经营管理内使用，不对顾客开放，不接入微信。
- 阶段 1 不新增接口和数据表，不需要数据库迁移。对话只保存在本浏览器的本次会话内，关闭标签页即清除。
- 是否需要按角色限制谁能看到小助手，阶段 2 与问答库一起确定；阶段 1 所有能进入经营管理的账号都可见。

## 5. 验收

| 编号 | 验收内容 |
| --- | --- |
| A1 | 九个经营管理页面标题栏右上角都有入口，位置一致，不与其他控件叠放 |
| A2 | 输入框浮现、发送后移到右侧、问答栏展开均为缓慢过渡；系统设置"减少动态效果"时不播放动画 |
| A3 | 问答栏打开后切换任意页面，问答内容不变；各页面没有内容被遮挡、没有横向滚动 |
| A4 | 宽度和高度可拖动，并在刷新后保持 |
| A5 | 经营总览不再有"刷新今日数据"；经营日期与数据更新时间在同一行靠右 |
| A6 | 管理端测试、类型检查、构建通过 |
