# 需求变更单：库存页面整理与商品停售、改名

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-020 |
| 关联需求 | CR-008（仓位）、CR-016（手机库存作业）、CR-017、CR-019 |
| 状态 | 开发完成（待门店电脑更新，无需数据库迁移） |
| 日期 | 2026-11-09 |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈（截图） | 临期预警表格中有一条渐变色线条横穿页面，要求删除 |
| 客户反馈 | 库存台账能看到商品仓位，库存盘点看不到，要求一致；台账与盘点的分工不清楚 |
| 客户反馈（截图） | 仓位管理每个货架卡片太大，按品牌放置在最下面，手机上要一直往下滑 |
| 客户反馈 | 已经不卖的商品需要能删除，否则商品越来越多 |
| 客户反馈 | 需要管理员能修改商品名称 |
| 客户确认 | 按"横线 → 盘点仓位 → 仓位页面 → 停售与改名"顺序开发；POS 新卖的商品会建新档案，停售商品不需要因 POS 销售自动恢复 |

## 2. 原因

| 编号 | 原因 |
| --- | --- |
| C1 | 临期预警表格外框的渐变发光装饰位于可滚动区域内，表格上下滚动时装饰跟着内容移动，形成横线 |
| C2 | 盘点页面数据中已包含仓位，但页面没有显示，也不能按仓位筛选 |
| C3 | 仓位以大卡片网格排列在前，按品牌放置在后 |
| C4 | 没有停售功能；商品状态"停用"已存在，台账、盘点、进货建议、临期预警均只显示在用商品，但没有入口 |
| C5 | 没有修改商品名称的入口 |

## 3. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 删除临期表格横线 | 去掉可滚动报表区域的渐变发光装饰，只改样式 |
| F2 | 盘点显示仓位 | 盘点列表每个商品显示仓位（未放显示"未放仓位"）；增加"按仓位"筛选，可选某个仓位或"未放仓位"；列表按仓位编码排序，同一货架的商品排在一起，便于从上数到下 |
| F3 | 台账与盘点分工说明 | 台账：查商品在哪、有多少、有哪些日期，单个商品增加/减少/改日期/改仓位。盘点：按货架逐个清点，填实际数量，系统算差额。两页顶部各一句说明 |
| F4 | 仓位页面重排 | 分为"放置商品"（默认）和"仓位列表"两个标签。放置商品即原按品牌放置；手机上"选择仓位 / 放到这个仓位"操作栏固定在屏幕底部。仓位列表改为紧凑行：编码、名称、区域层级、商品数、操作，下级缩进显示在上级下面；点"查看商品"切到放置商品并按该仓位筛出商品 |
| F5 | 商品停售 | 管理员在库存台账商品上点"停售"，填写原因。库存必须为 0，否则提示先盘点或出库。停售后商品状态为停用，不再出现在台账、盘点、进货建议、临期预警中；条码保留 |
| F6 | 已停售列表与恢复 | 库存台账增加"已停售"查看，列出停售商品、停售时间、原因、操作人，可"恢复销售"。停售商品再次扫码入库时自动恢复为在用，并在入库结果提示"该商品已恢复销售" |
| F7 | 管理员改名 | 管理员在库存台账商品上点“改名”，可改商品名称；同时显示中文名、英文名和 POS 名称作对照；名称不能为空、不超过 255 字。页面优先显示中文名，因此新名称同时写入商品名称和中文名，英文名保留 |
| F8 | 审计 | 停售、恢复、改名均写入审计记录（修改前、修改后、原因、操作人） |

## 4. 权限

| 操作 | 权限 |
| --- | --- |
| 盘点按仓位筛选、仓位页面 | 沿用现有规则 |
| 停售、恢复、改名 | 仅管理员 |

## 5. 不在本次范围

- 不新增数据库字段，停售使用商品已有的"停用"状态，无需迁移。
- POS 销售不会自动恢复停售商品（客户确认 POS 新卖商品会建新档案）。
- 批量改名通过数据清理表导入，另行处理。

## 6. 上线与回滚

| 步骤 | 内容 |
| --- | --- |
| 上线 | 门店电脑停服务 → `git pull` → `corepack pnpm build` → `corepack pnpm start:prod`；无数据库迁移 |
| 回滚 | 回到上一版本代码重启；已停售商品可在回滚前通过"恢复销售"恢复，或保留停用状态（旧版本同样不显示停用商品） |

## 7. 验收

| 编号 | 验收内容 |
| --- | --- |
| A1 | 临期预警表格上下滚动时不再出现横线 |
| A2 | 盘点页每个商品显示仓位；选仓位"地柜"只列出地柜的商品，并按仓位排序 |
| A3 | 仓位管理默认打开"放置商品"；手机上勾选商品后不滑动即可点"放到这个仓位"；仓位列表为紧凑行，下级缩进 |
| A4 | 库存为 0 的商品可停售，停售后台账、盘点、进货建议不再出现；有库存时不能停售 |
| A5 | 已停售列表可恢复；停售商品扫码入库后自动恢复 |
| A6 | 管理员可改名，非管理员看不到停售、改名按钮；操作有审计记录 |
| A7 | API、管理端测试与构建通过 |
