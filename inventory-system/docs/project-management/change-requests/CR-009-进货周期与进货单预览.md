# 需求变更单：进货周期按到货节奏、备货周期可调、进货单预览

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-009 |
| 关联需求 | 进货建议、本周进货单、CR-006（备货规则）、CR-007（品牌进货单） |
| 状态 | 开发完成（待上线，需数据库迁移） |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈 | 门店每周二到货入库，周六、周日写进货单；询问进货单何时刷新、建议是否按销量自动计算，要求系统的循环与实际节奏一致 |
| 客户反馈 | 本周进货单选好后需要一个预览弹窗：左侧药盒图形，向右发散线条连到商品名（按进货数量从上到下排列），最右侧为科技感面板，显示商品名称、库存、进货数量；预览、返回、下载按钮为椭圆液态玻璃样式，有呼吸感；下载内容与现有导出 Excel 相同 |
| 客户确认 | 同意开发端方案：周期改为周三至下周二、写单时手动重算、确认后锁定、备货周数调低；进货单在“进价与整箱”后增加“备货周期”，默认 2 周，可逐个商品调整；页面元素在框内排布，不得重叠挤压 |

## 2. 现状分析

| 项目 | 现状 | 问题 |
| --- | --- | --- |
| 进货单周期 | 按自然周（周一开始）建单，每周一换新单 | 周六、周日写的单到周一就成为“上周”单，周二到货时已不是本周单，对单错开一周 |
| 建议数量 | 每次打开页面按最近 28 天销量实时计算（缺货商品看 90 天）；目标库存按周销量分档备 4、5、6 周 | 每周进货的门店备货偏多，占用资金并增加临期风险 |
| 进货单数量 | 商品加入进货单时记录当时的库存与建议，之后不变 | 周中加入的商品到周末写单时数据已过时，只能逐个移除再加入 |
| 预览 | 只有表格和导出 Excel | 无法整体查看本周要进的货 |
| 到货对单 | 扫码入库不回写进货单“已到货数量” | 本次不处理，见第 5 节 |

## 3. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| P1 | 进货周期改为周三至下周二 | 本周进货单按门店时区的“最近一个周三”确定，周三 0 点起自动对应新单（首次加入商品时创建）。原按周一建立的进货单整体后移 2 天归入同一周期，单号不变 |
| P2 | 备货周期默认 2 周 | 进货建议与加入进货单的建议数量：目标库存 = 周销量 × 2 周（向上取整），建议数量 = 目标库存 − 当前库存。周销量不足 1 件的慢销品仍按陈列量（最低库存或默认 2 件）。“本周必买”标准不变（缺货、库存撑不到 2 周或低于最低库存） |
| P3 | 进货单逐个商品调整备货周期 | 进货单表格在“进价与整箱”之后增加“备货周期”列，显示“N 周”，下方有减、加按钮，范围 1–8 周。调整后按实时库存与销量重算建议数量；进货数量未手动改过的同步为新建议，手动改过的保持不变。仅草稿可调；写审计 |
| P4 | 按最新数据重算 | 草稿进货单增加“按最新数据重算”：所有商品按各自备货周期刷新库存、周销量、建议数量；未手动改过的进货数量同步更新。写审计 |
| P5 | 确认后锁定 | 沿用现有规则：确认后不能修改数量、备货周期，也不能重算；退回草稿后可再改 |
| P6 | 进货单预览 | “导出 Excel”旁增加“预览”胶囊按钮（液态玻璃、呼吸光晕；无商品时不可点）。弹窗三栏：左侧药盒线稿与光环、单号与合计；中间从药盒发散的弧线连接商品名，按进货数量从多到少由上至下排列，数量越多线越亮越粗，最多 20 条，其余合并为“+ 其余 N 项”；右侧玻璃面板列出全部商品的名称、当前库存、进货数量（确定进货数量），可滚动。悬停面板行时对应线条高亮。底部“返回”（青蓝）、“下载”（绿色）为同款小号胶囊；返回关闭预览（Esc、点击空白也可），下载与现有“导出 Excel”内容相同。手机宽度只显示面板。系统设置“减少动态效果”时关闭动画。各区域在弹窗内排布，商品名过长省略显示，不重叠 |

## 4. 影响评估

| 方面 | 影响 |
| --- | --- |
| 数据库 | 迁移 `202610310001_purchase_cycle_coverage`：`purchase_order_items` 新增 `coverage_weeks`（默认 2）与 `quantity_edited`（默认否）；`purchase_orders.week_start` 原周一周期整体加 2 天。回滚：删除两列，`week_start` 减 2 天 |
| 进货建议 | 建议数量整体下降（备货周数 4–6 周改为 2 周），本周必买商品数不变 |
| 现有进货单 | 本周草稿单保留全部商品与数量，自动成为新周期的本周单 |
| 库存与 POS | 不影响 |
| 上线 | 需执行数据库迁移；先在开发库验证，再在 Windows 正式环境执行 |

## 5. 不在本次范围

- 扫码入库自动回写进货单“已到货数量”、全部到货自动结单：需要确定一次到货对应哪张单（跨周补货、部分到货），另行确认后实施。
