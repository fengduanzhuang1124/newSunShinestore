# 需求变更单：品牌进货单、操作按钮布局、按日经营总览与销售明细

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-007 |
| 关联需求 | 进货建议（CR-005、CR-006）、REQ-008（经营管理界面） |
| 提出日期 | 2026-10-26（客户反馈） |
| 状态 | 开发完成（待上线） |

## 1. 变更来源

| 日期 | 渠道 | 内容摘要 |
| --- | --- | --- |
| 2026-10-26 | 客户反馈 | 帕氏（parrs / PARRS / 帕氏 / 帕式）、coco brownie、Metoday、Haab 四个品牌单独向品牌方订货，进货建议需按品牌各成一张单，且不出现在总进货单中 |
| 2026-10-26 | 客户反馈 | 进货建议每行的操作按钮拥挤，需两列均衡排布 |
| 2026-10-26 | 客户反馈 | 经营总览只显示当天，希望可选择任意一天，各数据对应所选日期 |
| 2026-10-26 | 客户反馈 | 点击销售件数打开的商品明细需更好的展示：动态打开、每页 50 个商品、显示每个商品销量 |

## 2. 变更内容

| 编号 | 变更 | 规则 |
| --- | --- | --- |
| E1 | 品牌进货单 | 进货建议分为“总进货单”“帕氏”“coco brownie”“Metoday”“Haab”五张单，顶部切换并显示各自数量。品牌按商品名称、英文名、品牌名、POS 名称识别（不区分大小写）：帕氏 = parrs、parra、prres、帕氏、帕式；coco brownie = coco brow（含 brownie、browinie 等拼写）；Metoday；Haab。品牌商品只出现在本品牌单中。每张单内仍有“全部 / 本周优先 / 后续跟进 / 已忽略”筛选 |
| E2 | 操作按钮布局 | 每行操作按两列两行排布：加入进货单、忽略 / 调库存、合并同款，宽度一致，不挤压不重叠；手机端同样两列 |
| E3 | 按日经营总览 | 经营日期可点击选择任意一天（不晚于今天）；销售额、订单、件数、客单价、较前一日对比、销售明细均按所选日期计算。库存与到期数据为当前实时数据，页面注明“当前” |
| E4 | 销售明细 | 点击销售件数，从右侧（手机为底部）平滑展开明细面板；显示所选日期的商品数、件数；按销量排名，每行显示名次、商品、品牌、件数及相对销量条；每页 50 个，可翻页、可搜索；运费不计 |

## 3. 影响评估

| 方面 | 影响 |
| --- | --- |
| 数据库 | 无变更 |
| 进货建议 | 计算规则不变，仅分组显示；品牌规则可扩展 |
| 经营总览 | 接口已支持按日期查询，前端增加日期选择 |
| 上线 | 合并代码即可 |
