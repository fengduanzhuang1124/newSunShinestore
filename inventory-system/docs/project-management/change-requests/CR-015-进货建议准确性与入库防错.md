## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈 | 本周系统进货单（PO-20261102-1，44 个商品）与人工盘点进货清单（26 组）差别很大，要求说明原因 |
| 正式库只读核查 | 两边相同的约 19 个。人工有、系统没有的，主要原因是系统库存比实物多，系统据此判断"不需要进货" |

## 2. 差异原因

| 编号 | 原因 | 实例 |
| --- | --- | --- |
| R1 | 新品入库数量录多 | Zuru 捏捏录 12（实到 8）；Cath Kidston 沐浴 5 件套录 5、红莓护手霜 3 件套录 6，实物已有一款卖完 |
| R2 | 入库时记到别的商品 | 护手霜 288 个记到了 Alpine 蜂蜜香皂条码 9417657626544（POS 中该条码为香皂），香皂系统显示 257 个，实际基本没货 |
| R3 | 重复档案 | "sambucol接骨木泡腾片"（条码 40107271）为初始导入留下的档案，POS 中没有，系统显示 15 个，实物没有 |
| R4 | 同一入库单重复录入（待核对发票） | 入库单 RK-20261103-8D4EA5 中 17 个商品同一天按相同数量录了 2–5 次，若均为重复，多出 932 件（如高之源鱼油 1500mg 共 288、纽乐辅酶 30 粒 48×4、红印牙膏多款 48×3） |
| R5 | 建议被"忽略"后永久隐藏 | jack links 胡椒味（断货，28 天卖 41 个）、Swisse 儿童鱼油、高之源白瓶等，忽略没有期限 |
| R6 | 新品按 28 天平均计算 | 到货几天卖得快的新品，周销量被平均摊薄，系统判断库存足够 |
| R7 | 断货超过 90 天看不到需求 | Swisse 儿童钙、雅漾防晒等 90 天无销售，不再建议 |
| R8 | 临界值不补 | 库存正好等于两周用量时不建议（如 BePure 镁 3/3） |
| R9 | 页面显示近 7 天销量，建议按近 28 天计算 | 员工无法从页面数字看出建议数量的来源 |
| R10 | 系统没有该商品档案 | 红印铁片、好健康芦荟胶囊、美丽诺 500g 绵羊油 |

## 4. 系统变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| P1 | 新品按到货后卖出速度补货 | 首次入库 14 天内的商品，按"到货后日均销量 × 14 天 − 当前库存"计算建议数量；页面标注"新品"和到货后卖出数量 / 到货数量 |
| P2 | 入库重复提醒 | 同一入库单中，同一商品、同样数量再次录入时提示"已录过 N 件，是否为新到货" |
| P3 | 入库显示 POS 名称 | 扫码后显示该条码在 POS 中的名称，与选中的商品名不一致时提示，减少记错商品 |
| P4 | 忽略有期限 | 原因为"库存足够""临期处理"的忽略，14 天后自动恢复建议；其他原因保持不变 |
| P5 | 断货商品回看 180 天 | 当前无库存的商品按 180 天销量判断是否建议，与缺货列表一致 |
| P6 | 进货页显示近 28 天销量 | 与建议数量算法一致，保留近 7 天销量作参考 |

## 5. 不在本次范围

- 员工在入库时直接修改商品名称：商品名称跟随条码与 POS，随意改名会影响全部历史记录与报表；以 P3 防止选错，录错的行用已有的"撤销"功能纠正。
- 到期日期要求（如"27 年 8 月不要"）、整箱规格提醒：另行确认。
