# 需求变更单：功能需求细分与人群桑基图

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-021 |
| 关联需求 | REQ-014（商品分类与功能）、CR-011（店铺经营发现） |
| 状态 | 开发完成（待门店电脑更新，无需数据库迁移） |
| 日期 | 2026-11-09 |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈 | "为谁买"中中老年居多，希望按护心、护肝等功能更细分 |
| 客户要求 | 人群（中老年、女性、婴幼儿等）与功能分开；功能分区要更详细；用桑基图展示 |
| 代码核查 | 中老年大部分由功能推断（关节、心脑血管、护心、血糖、血压、尿酸商品自动计入中老年），不是商品本身写明，桑基图会反映规则而不是真实情况 |

## 2. 市场依据（摘要）

| 来源 | 内容 |
| --- | --- |
| 前瞻产业研究院（电商数据 2022-05 至 2023-04） | 中老年保健食品热门方向为心脑血管、骨骼关节、眼部健康；补钙、关节、免疫、心脑血管为关注重点 |
| Grand View Research（澳新膳食补充剂） | 老年消费者偏好骨骼、心脏、关节类补充剂 |
| Persistence Market Research（澳新草本补充剂） | 消化与心脏为最大应用细分，骨骼关节为独立细分 |
| 新京报（天猫健康 2024 数据） | 护肝片热度增长主要来自 20–25 岁人群的解酒护肝，不宜默认归为中老年 |

## 3. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 人群只按商品写明 | 人群来自商品名称中写明的人群词（婴、儿童、青少年、孕、女士、男士、中老年/50+ 等），以及伴手礼品类、奶粉母婴品类。取消由功能推断中老年；"女性健康""男性健康""孕产""儿童成长"等人群专项功能仍计入对应人群。没写明的为"家庭通用" |
| F2 | 功能两级分类 | 功能分为 9 个大类：心脑血管、骨骼关节、代谢管理、器官养护、免疫与精力、脑与情绪、美容抗衰、人群专项、外用护理；大类下为细分（见附表）。一个商品可有多个细分 |
| F3 | 桑基图 | 店铺经营发现中新增"人群 → 功能大类 → 功能细分"桑基图，线宽为本期商品销售额（按商品标价）。一个商品属于多个人群或细分时，销售额平均分配，总额等于实际商品销售额。没有识别出功能的商品归入"无明确功能"，第三层显示其品类 |
| F4 | 节点数量控制 | 电脑上功能大类显示前 7 个（沿用经营页面 7 色配色），其余合并为“其他大类”；功能细分显示前 10 个，其余合并为“其他细分”；人群全部显示。商品明细显示前 10 个，在列表内滚动 |
| F5 | 节点明细 | 点击节点，右侧（窄屏在下方）列出“该节点 · 卖得最好的商品”（最多 10 个）：计入金额、本期销量、库存、可卖周数。缺货或不足 2 周且不在本周进货单的商品显示“提醒进货”，点击加入本周进货单；已在进货单的显示“已在进货单”，其余显示“库存够用” |
| F6 | 手机显示 | 屏幕窄于 720px 时改为逐层横条：先人群，点人群看功能大类，再点看细分（按“人群-大类-细分”明细准确计算）；下方商品明细为该节点全部人群的商品，标题注明“全部人群” |
| F7 | 口径说明 | 页面注明"人群按商品写明判断；一个商品属于多个功能时销售额平均分配" |

## 4. 附表：功能两级分类

| 大类 | 细分 |
| --- | --- |
| 心脑血管 | 护心（Q10）、鱼油与 Omega-3、血脂胆固醇、血管循环 |
| 骨骼关节 | 关节、补钙与维 D、补镁 |
| 代谢管理 | 血糖、血压、尿酸与痛风、体重管理 |
| 器官养护 | 护肝、护眼、益生菌、消化通便、呼吸与咽喉、泌尿健康 |
| 免疫与精力 | 免疫力、能量与抗疲劳、补铁补血、综合营养、解酒 |
| 脑与情绪 | 睡眠、情绪压力、健脑益智 |
| 美容抗衰 | 胶原蛋白、美容养颜、抗氧化与抗衰、头发 |
| 人群专项 | 女性健康、男性健康、孕产、儿童成长 |
| 外用护理 | 保湿补水、修护、抗皱紧致、美白提亮、祛疤、防晒、舒缓敏感、牙齿美白去渍、防蛀、牙龈护理、清新口气 |

## 5. 不在本次范围

- 市场行情数值对照（每个细分的市场热度）需要稳定的数据来源，另行确认。
