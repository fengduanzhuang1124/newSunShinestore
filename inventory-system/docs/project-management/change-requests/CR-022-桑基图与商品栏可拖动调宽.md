# 需求变更单：桑基图与商品栏可拖动调宽

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-022 |
| 关联需求 | CR-021（人群与功能需求桑基图） |
| 状态 | 开发完成（待门店电脑更新，无需数据库迁移） |
| 日期 | 2026-11-10 |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈 | 市场分析“人群与功能需求”右侧“卖得最好的商品”看不清楚，希望能左右拖动调整两块的宽度 |

## 2. 原因

| 编号 | 原因 |
| --- | --- |
| C1 | 电脑上商品栏固定 340px，商品名只显示一行，长名称被截断 |
| C2 | 计入金额、本期件数、库存一行在窄栏里容易换行，不易对比 |

## 3. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 分隔条拖动调宽 | 电脑宽屏（1200px 以上）桑基图与商品栏之间加竖向分隔条，鼠标移上显示左右箭头和“拖动调整宽度，双击恢复默认”提示；拖动时桑基图按新宽度重新排版，文字不缩放 |
| F2 | 宽度范围 | 商品栏最窄 300px、最宽为整块宽度的 55%；桑基图最窄 560px |
| F3 | 记住宽度 | 拖好的宽度保存在本机浏览器，下次打开沿用；双击分隔条恢复默认宽度；浏览器不允许保存时照常使用默认宽度 |
| F4 | 键盘调整 | 分隔条可用 Tab 选中，左右方向键每次调整 20px，Home 键恢复默认 |
| F5 | 默认更宽、名称不截断 | 商品栏默认宽度 340px 改为 400px；商品名最多显示两行，超出才省略 |
| F6 | 手机与窄屏不变 | 1200px 以下商品栏在图下方占整行，不显示分隔条 |

## 4. 上线与回滚

| 步骤 | 内容 |
| --- | --- |
| 上线 | 门店电脑停服务 → `git pull` → `corepack pnpm build` → `corepack pnpm start:prod`；只改管理端，无接口、数据库变化 |
| 回滚 | 回到上一版本代码重启 |

## 5. 验收

| 编号 | 验收内容 |
| --- | --- |
| A1 | 电脑上拖动分隔条，商品栏在 300px 到整块 55% 之间变化，桑基图随之重新排版、文字不变形 |
| A2 | 刷新页面后保持上次拖好的宽度；双击分隔条恢复默认 |
| A3 | 键盘选中分隔条后方向键可调宽 |
| A4 | 长商品名显示两行；手机上无分隔条，布局与之前一致 |
| A5 | 管理端测试与构建通过 |
