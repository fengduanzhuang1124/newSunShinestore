# 需求变更单：暂不进货周数与进货周期调整

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-018 |
| 关联需求 | CR-009（进货周期）、CR-015 P4（忽略有期限） |
| 状态 | 开发完成（待门店电脑更新，无需数据库迁移） |
| 日期 | 2026-11-09 |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈 | 某个商品这周不进货，下周还会不会出现？希望能选择 2 周、4 周内不进货，选好周数再点"不进货" |
| 客户反馈（截图） | 进货单取消后仍可预览、导出，看起来像没取消成功 |
| 客户要求 | 每周应在周一晚上更新为新一周的进货 |
| 代码核查 | 进货建议的"忽略"是永久隐藏，没有期限；进货单移除商品后，下周该商品仍会出现在进货建议中；取消实际已生效（状态为已取消，不能再加商品），只是预览、导出按钮没有隐藏；进货周期为周三至下周二（CR-009） |

## 2. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 暂不进货（选周数） | 进货建议每行可选"本周 / 2 周 / 4 周 / 长期"后点"不进货"。按周数隐藏到对应那一周的周一 18:00 自动恢复；"长期"等同原来的忽略，需手动恢复 |
| F2 | 进货单内不进货 | 本周进货单每行同样可选周数后点"不进货"：从本周进货单移除，并按周数暂不出现在进货建议中 |
| F3 | 显示恢复时间 | "已忽略"列表显示暂不进货的恢复时间，可随时手动恢复 |
| F4 | 进货周期 | 改为周二至下周一，每周一 18:00（门店时间）切换到新一周；本周已建的进货单（PO-20261102-1）归入当前周期，不受影响 |
| F5 | 已取消的进货单 | 不再显示预览和导出，显示"本周进货单已取消"及"恢复为草稿" |

## 3. 不在本次范围

- 不新增数据库字段：暂不进货沿用已有的恢复时间字段。
- CR-015 P4（"库存足够""临期处理"14 天自动恢复）待 CR-015 确认后再做。
