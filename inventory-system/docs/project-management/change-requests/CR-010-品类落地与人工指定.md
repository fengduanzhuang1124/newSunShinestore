# 需求变更单：品类在经营管理全面使用、按功效与人群筛选、未识别商品人工指定

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-010 |
| 关联需求 | REQ-014（市场分析）及附件《品类、功效、人群分类》 |
| 状态 | 开发完成（待上线，无需数据库迁移） |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户确认 | 品类、功效、人群分类全部确认；暂不接入大模型接口 |
| 客户确认 | 同意开发端建议：品类在查询时自动识别，不批量写入商品资料；只有人工指定的品类写入；先让品类在商品分析、库存经营等页面使用，并提供未识别商品的人工指定 |

## 2. 现状

| 项目 | 现状 | 问题 |
| --- | --- | --- |
| 商品资料品类字段 | 3727 个在用商品全部为空 | 商品分析“品类结构”、商品明细、库存经营、进货建议几乎全部显示“未标注品类” |
| 品类筛选 | 商品分析、销售分析按商品资料品类字段在数据库中模糊查询 | 字段为空，筛选无结果 |
| 自动识别 | 仅市场分析使用（REQ-014） | 其他页面未使用 |
| 人工修正 | 无入口 | 识别不了的商品（近 90 天有销售的约 70 个）无法归类 |

## 3. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 品类统一显示 | 商品分析（明细、品类结构）、销售分析（品类排行）、库存经营、进货建议、本周进货单、数据中心资料完整率统一使用“人工指定优先、否则按名称自动识别”的品类，显示二级品类，并附一级品类 |
| F2 | 按品类、功效、人群筛选 | 商品分析与销售分析的品类筛选改为下拉选择（按一级品类分组）；商品分析增加功效、人群筛选。筛选在识别之后进行，结果与显示一致 |
| F3 | 未识别商品人工指定 | “分类与标签”页新增“品类指定”：默认列出未识别的商品（按近 90 天销量从高到低），也可搜索任意商品查看或修改；从分类表中选择二级品类后保存，可清除人工指定恢复自动识别。仅管理员可修改；写审计（原品类、新品类） |
| F4 | 分类表接口 | 提供分类表（品类、功效、人群）供页面下拉使用，与 REQ-014 附件一致 |

## 4. 影响评估

| 方面 | 影响 |
| --- | --- |
| 数据库 | 无结构变更、无迁移。人工指定写入商品资料已有的品类字段（`products.category_name`），保存二级品类名称；清除即置空 |
| 自动识别 | 不写入数据库；规则改进后所有未人工指定的商品立即按新规则显示 |
| 核心补货判断 | 原有规则会把名称或品类含“绵羊油”的商品视为核心补货商品（默认最低库存 20）。人工指定为“绵羊油系列”的商品因此进入核心补货，符合实际（均为绵羊油产品） |
| 筛选性能 | 品类筛选需先读取门店在用商品并识别（约 3700 个），实测识别全部商品耗时在毫秒级 |
| POS、库存 | 不影响 |
| 上线 | 无需数据库迁移，随代码更新生效 |

| 动作 | 人员 | 说明 |

| 确认 | 甲方 | 分类确认；自动识别 ＋ 人工指定写入的方案 |
| 分析与方案 | 开发 | 见第 2–4 节 |
| 开发完成 | 开发 | 接口：`GET /management/product-taxonomy`、`GET /management/product-categories`（未识别 / 已人工指定 / 全部，可搜索）、`POST /management/product-categories/assign`（仅管理员，写审计）；商品分析增加 `functionTag`、`audience` 参数。商品分析、销售分析、库存经营、进货建议、本周进货单、商品标签页与数据中心资料完整率统一使用识别后的品类；商品分析与销售分析品类改为分组下拉，商品分析增加功效、人群筛选，明细显示前两个功效；“分类与标签”新增“品类指定”。开发库实测：识别率 77.1%（2874 / 3727）；绵羊油系列 79 种、护肝 18 种；未识别 853 种，其中近 90 天有销售 70 种；商品分析 0.16 秒、销售分析按品类 0.2 秒。测试：API 255、管理端 71 项通过；类型检查、构建通过；无头浏览器检查品类指定（深浅色、手机）与商品分析筛选区，无重叠、无横向滚动 |
| 页面调整 | 开发 | 根据客户查看意见（现场查看商品分析页）：筛选栏在桌面宽度下改为一行并缩小；日期和下拉选项改动后自动更新，商品搜索与品牌输入后按回车或点“查询”（原“更新分析”）；去掉“商品分析口径”说明块，必要说明并入明细表副标题；六张汇总卡改为一行汇总条（缺货、低库存可点击到库存经营）；映射率提示仅在低于 99% 时显示 |
