# 需求变更单：直邮商品、进货建议规则改进与盘点防错

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-005 |
| 关联需求 | REQ-012（盘点任务）、进货建议（本周进货）、REQ-008（经营管理界面） |
| 提出日期 | 2026-10-25（客户反馈） |
| 状态 | 开发完成（待上线） |

## 1. 变更来源

| 日期 | 渠道 | 内容摘要 |
| --- | --- | --- |
| 2026-10-25 | 客户反馈 | Anchor Blue Milk Powder 1kg、Anchor Trim cream 1kg SF*6 为直邮商品，不占门店库存，不应扣减 |
| 2026-10-25 | 客户反馈 | 实际进货单与系统进货建议差异较大；经逐项对照（`outputs/20261025-purchase-compare/`），原因包括断货商品无销量、忽略不失效、“近 7 天已到货”判断过粗、商品档案缺失 |
| 2026-10-25 | 内部发现 | 盘点中出现 100,000 件的误录；盘点流水来源未标明；部分盘点商品未对应 POS |
| 2026-10-25 | 客户反馈 | 进货建议卡片需更简洁、可读性更好 |

## 2. 变更内容与规则

| 编号 | 变更 | 规则 |
| --- | --- | --- |
| C1 | 直邮商品标记 | 门店商品增加“直邮”标记。直邮商品 POS 卖出不扣库存（明细标记为直邮，不进入复核）；不进入缺货、低库存与进货建议；可在库存经营与盘点面板中设置或取消，写审计。原按名称识别的直邮奶粉规则保留 |
| C2 | 断货商品的销量依据 | 当前库存 ≤ 0 时，近 28 天销量取“近 28 天实际”与“近 90 天按 28 天折算”中的较大值，避免断货期间无销量而永不建议 |
| C3 | 忽略的有效期 | 进货建议中的手动忽略 30 天后自动失效，或在库存降为 0 时失效；盘点中标记“不再销售”的忽略长期有效 |
| C4 | “已到货”判断 | 近 7 天有入库但按规则仍不足的商品照常建议，并标注“近 7 天已入库 X 件”；不再整体隐藏 |
| C5 | 盘点防错 | 单个批次数量上限 9,999；数量 ≥ 500，或为系统数量 10 倍以上且相差 ≥ 100 时，确认前需再次确认 |
| C6 | 流水来源 | 盘点任务产生的流水显示为“盘点任务” |
| C7 | POS 未对应提示 | 盘点面板中提示“POS 未对应，卖出不会扣库存”；另出 POS 未对应商品清单供补对应 |
| C8 | 进货建议卡片 | 简化为：商品名、一行关键数字（库存 · 周销 · 可卖周数）、醒目的建议数量、紧凑的“加入 / 忽略”操作；去掉三格数字框 |

## 3. 影响评估

| 方面 | 影响 |
| --- | --- |
| 数据库 | `store_products` 增加 `direct_ship`（默认 false，向后兼容） |
| POS 扣库 | 直邮商品不再扣减；其他商品不变 |
| 进货建议 | 建议数量与范围变化（C2–C4），更多断货商品会出现在建议中 |
| 页面 | 进货建议卡片样式、盘点面板、库存经营增加直邮操作 |
| 上线 | 需执行迁移，顺序：备份 → 迁移 → 合并 → 重新生成数据库客户端并重启 API |

## 5. 开发结果

| 编号 | 实现 |
| --- | --- |
| C1 | 迁移 `202610250001_store_product_direct_ship`；`POST /management/products/direct-ship`（库存经营每行“设为直邮/取消直邮”）与 `POST /inventory/count-tasks/:taskId/items/:itemId/direct-ship`（盘点面板；待盘点商品同时改为已忽略）；均写审计 `store_product.direct_ship`。POS 扣库对直邮商品标记 `DIRECT_SHIP`，不扣减、不进复核清单。按名称识别的直邮奶粉仍照常扣减（保持现有行为） |
| C2 | 进货建议按近 90 天销量统计；库存 ≤ 0 时取两者较大值，返回 `salesBasis`；卡片标注“断货中，按近 90 天销量估算” |
| C3 | 共用规则 `ignoreIsActive`：手动忽略 30 天或库存为 0 时失效；“下周显示”到期失效；“盘点时标记不再销售”长期有效。库存经营与进货建议同口径 |
| C4 | 取消“已到货”分组；近 7 天有入库但仍不足的照常建议，卡片标注“近 7 天已入库 X 件，仍不足” |
| C5 | 接口单批次上限 9,999（中文提示）；页面同样校验；≥ 500 或 ≥ 10 倍且相差 ≥ 100 时需再次确认 |
| C6 | 盘点任务流水在流水列表显示“盘点任务” |
| C7 | 盘点面板提示“POS 未对应，卖出不会扣库存”；清单 `outputs/cr-005/POS未对应商品清单_20261025.xlsx`（66 种，不提交） |
| C8 | 卡片改为：商品名、品牌、一行“库存 · 周销 · 可卖周数/已断货”、标注、醒目的“建议 N”与“加入/忽略”；桌面 3 列、中屏 2 列、手机 1 列（手机操作在卡片底部一行） |

测试与演练见 `docs/records/cr-005-test-report.md`。
