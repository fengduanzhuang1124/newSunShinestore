# 需求变更单：台账零库存日期与按品牌建仓位

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-017 |
| 关联需求 | CR-008（仓位与按品牌放置）、CR-016 |
| 状态 | 开发完成（待门店电脑更新，无需数据库迁移） |
| 日期 | 2026-11-09 |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈（截图） | 库存台账搜索出的商品，库存为 0 的日期仍然一行行占位（如还原型辅酶 Q10 显示 4 个日期，只有一个有 138 件） |
| 客户反馈 | 仓位管理希望按品牌选位：一个品牌可能放一整个货架，首次录入按品牌放置省时间，之后可以在二级、三级位置再细分 |
| 正式库只读核查 | 当前仓位 0 个；"按品牌放置"功能已存在，但页面在有仓位后才显示，客户看不到；商品品牌字段全部为空，品牌从商品名识别 |

## 2. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 隐藏零库存日期 | 库存台账、出库、入库搜索结果只显示数量不为 0 的日期；负数仍显示，便于核查；全部为 0 时显示"暂无日期库存"。库存增加时仍可选择原有日期 |
| F2 | 按品牌放置始终可见 | 没有仓位时也显示品牌列表；选中品牌后可直接"为该品牌新建仓位"，名称默认"品牌 货架"，保存后即可把该品牌商品一次放上去 |
| F3 | 二级、三级细分 | 每个仓位卡片增加"添加下级"：编码自动带上上级编码前缀（如 SW-01 → SW-01-2），区域、通道、货架沿用上级；下级最多到三级（编码中两个连接号） |
| F4 | 仓位按编码排序 | 下级紧跟在上级后面显示，并标注"N 级 · 属于 上级编码 名称" |

## 3. 不在本次范围

- 不新增数据库字段：层级由编码前缀表示，不需要迁移。
- 商品名称统一与品牌字段补齐：按名称标准化表由客户核对后，另行导入。
