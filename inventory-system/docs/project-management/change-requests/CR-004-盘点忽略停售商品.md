# 需求变更单：盘点任务中忽略停售商品

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-004 |
| 关联需求 | REQ-012 手机逐项盘点任务 |
| 提出日期 | 2026-10-24（客户反馈） |
| 状态 | 开发完成，待上线 |

## 1. 变更来源

| 日期 | 渠道 | 内容摘要 |
| --- | --- | --- |
| 2026-10-24 | 客户反馈 | 盘点时部分商品已停售（如部分奶粉、Jellycat），需在盘点页面提供“忽略”操作：不盘点数量，商品资料继续保留在系统中 |

## 2. 变更内容

| 项目 | 变更前 | 变更后 |
| --- | --- | --- |
| 盘点商品状态 | 待盘点、已确认 | 增加“已忽略” |
| 核对面板 | 只能确认 | 增加“不再销售，忽略”按钮（二次确认） |
| 分组 | 高 / 中 / 低 / 已完成 | 增加“已忽略”分组，可一键恢复为待盘点 |
| 进度 | 剩余 = 待盘点 | 忽略的商品不计入剩余；全部确认或忽略后任务完成 |

## 3. 业务规则

| 编号 | 规则 |
| --- | --- |
| C1 | 忽略不产生库存流水，系统库存数量保持不变；商品资料、条码、历史流水全部保留 |
| C2 | 忽略写审计记录（操作人、时间、商品、当时库存）；恢复同样记录 |
| C3 | 已忽略的商品可随时恢复为待盘点 |
| C4 | 忽略时默认同时在经营管理的缺货提醒与进货建议中忽略该商品（可取消勾选），与经营管理“忽略”写入同一记录，可在经营管理中恢复；从盘点恢复不会自动取消进货忽略 |

## 4. 影响评估

| 方面 | 影响 |
| --- | --- |
| 数据库 | 盘点明细状态枚举增加 `IGNORED`（版本化迁移，向后兼容；回滚前需把 `IGNORED` 改回 `PENDING`） |
| 接口 | 新增忽略、恢复两个操作；任务进度计算调整 |
| 页面 | 核对面板增加按钮、增加“已忽略”分组 |
| POS 扣库 | 无影响（忽略的商品照常按销量扣减） |
| 上线 | 需要执行迁移，步骤与 REQ-012 相同（备份 → 迁移 → 合并） |

## 5. 待甲方决定

| 编号 | 事项 | 建议 |
| --- | --- | --- |
| D1 | 忽略的作用范围 | 只影响本次盘点；系统库存数量不变 |
| D2 | 是否同时在经营管理“缺货 / 进货建议”中忽略 | 是，忽略面板中默认勾选“同时不再建议进货”，可取消 |
| D3 | 是否需要按品牌批量忽略 | 暂不需要：当前清单只有 6 种奶粉、无 Jellycat，逐个忽略即可 |
