# 需求变更单：店铺经营发现按"买了什么、为谁买"重做；市场分析页面层级调整

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-011 |
| 关联需求 | REQ-014（市场分析）、CR-010（品类落地） |
| 状态 | 开发完成（待上线，无需数据库迁移） |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户查看开发环境后提出 | 市场分析首页已有四个模块，进入后顶部又列出四个模块，层级重复；进入模块后应切换该模块自己的内容 |
| 客户查看开发环境后提出 | 店铺经营发现的品类升降几乎全是负值，看不出重点；希望参考巨量千川的商品分析，用图形和文字展示品类、人群、覆盖情况 |
| 客户确认 | 人群按顾客购买的商品判定（这是实际有需求的人群）；一个订单可以同时属于多个人群，允许重复计算（顾客可能为全家购买）；分析的目的是看近期买了什么，据此决定经营重点：伴手礼多则重视游客产品，护肤品多则增加护肤品广告曝光，中老年商品多则针对推出商品和活动，滞销及时提醒并策划活动 |
| 客户确认 | 趋势线、环形图、组合卡片等图形合理分布，不堆在一页 |

## 2. 现状与问题

| 项目 | 现状 | 问题 |
| --- | --- | --- |
| 统计区间 | "近 7 天"等区间包含尚未结束的今天；数据同步中断时也照常截至今天 | 本期天数不足，与完整的上期比较，几乎所有品类都显示大幅下降（开发库数据只到某日上午，本期只有两天多数据，品类普遍显示 -50% 至 -90%） |
| 页面层级 | 首页四个模块卡片；进入后顶部又是四个模块切换 | 首页入口与顶部切换重复 |
| 店铺经营发现内容 | 四个计数卡（突然热销、超量滞销、常一起买、品类上升）加一张品类件数对比表 | 没有销售额、订单、客单价等基础指标；没有人群；只按件数百分比比较，看不出哪个品类真正影响了销售；没有结论和建议 |

## 3. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 统计区间只用完整的天 | 本期截至昨天；若最近一笔订单早于昨天（同步中断或开发库副本），本期截至该订单前一天（该天可能不完整），页面显示"数据截至某日"。上期与本期天数相同，紧接在本期之前 |
| F2 | 页面层级 | 市场分析首页保留四个模块卡片和"本期要点"；店铺经营发现上方为一排四张卡片：经营画像（概览、买了什么、为谁买、经营重点）、商品榜（热销榜、突然热销、下滑榜、热销缺货、滞销与临期）、品类与时段、连带购买；点击卡片后下方切换为该卡片的详细内容，内容逐块缓慢出现，折线逐步画出、条形逐步伸展。选中的卡片高亮并缓慢呼吸。返回按钮为液态玻璃呼吸样式，返回市场分析首页 |
| F3 | 店铺经营发现内容分组 | 经营画像（原概览与人群）、商品榜（原商品榜与滞销待处理）、品类与时段（原品类与时段）、连带购买，共四组 |
| F4 | 经营画像 | 买了什么（一级品类占比条）、为谁买（人群，见 F6）、经营重点（见 F9）。销售额、订单数、客单价、销售件数、动销商品数和每日销售额已在"经营总览"展示，这里不重复；顶部卡片保留销售额与小曲线作为提示 |
| F5 | 品类 | 一级品类销售额占比环形图；二级品类"拉动与拖累"条形图：按与上期相比的销售额增减排序，显示金额而非只显示百分比 |
| F6 | 人群 | 按购买的商品判定需求人群（见第 4 节），统计每个人群的订单数、占全部订单的比例、销售额及与上期的比例变化；一个订单可计入多个人群，比例合计可超过 100%；每个人群显示买得最多的品类 |
| F7 | 商品榜 | 热销榜（销售额前 10，附近五期销量小趋势线和库存可卖周数）、突然热销与新品起量（沿用原规则）、下滑榜（上期至少 5 件且本期下降 30% 以上，按减少件数排序） |
| F8 | 时段 | 星期 × 小时的订单数热力图，标出最忙的时段 |
| F9 | 经营重点（规则生成，不接入大模型，不建议价格） | 热销但库存不足（建议加入本周进货单）；临期滞销（建议近期策划清货活动）；人群比例较高或明显上升时给出对应建议；护肤品等品类占比较高或明显上升时给出对应建议；下降最多的品类提示检查缺货或安排活动。最多显示 5 条，每条附依据数字 |
| F10 | 连带购买、滞销与待处理 | 沿用原规则，改为分页展示；连带购买以组合卡片展示 |

## 4. 需求人群判定

按商品名称、品类和功效判定；一个商品可属于多个人群。

| 人群 | 判定依据 |
| --- | --- |
| 游客（伴手礼） | 二级品类为蜂蜜、绵羊油系列、蜂胶与蜂产品保健、香皂、喉糖与蜂蜜糖果，或名称含"礼盒、伴手礼、gift"。**此清单为初始版本，客户可要求增减** |
| 婴幼儿 | 名称含婴、baby、宝宝等；或二级品类为婴幼儿与儿童奶粉、母婴用品 |
| 儿童 | 名称含儿童、kids 等；或功效为儿童成长 |
| 青少年 | 名称含青少年、teen |
| 孕产 | 名称含孕、elevit 等；或功效为孕产 |
| 女性 | 名称含女、women 等；或功效为女性健康 |
| 男性 | 名称含男、men 等；或功效为男性健康 |
| 中老年 | 名称含中老年、50+ 等；或功效为关节、心脑血管、护心、血糖平衡、血压、尿酸与痛风 |
| 家庭通用 | 以上都不符合的商品 |

页面注明："人群按所购商品判定，代表购买需求，不是顾客本人的年龄或性别。"

## 5. 经营重点规则

| 条件 | 显示内容与建议 |
| --- | --- |
| 突然热销且库存约够不到 2 周、未加入本周进货单 | 热销但库存不足 N 种 → 加入本周进货单 |
| 超量滞销中有临期商品 | 临期滞销 N 种 → 近期策划清货活动，到库存经营查看 |
| 人群订单占比 ≥ 15%，或比上期上升 ≥ 3 个百分点 | 游客：重视游客产品，增加陈列、备货和礼盒组合；中老年：针对中老年推出商品组合和活动；婴幼儿、儿童、孕产：加强母婴儿童专区和组合推荐；女性、男性：做专项推荐。按上升幅度取前两条 |
| 一级品类销售额占比 ≥ 25%，或比上期上升 ≥ 3 个百分点 | 护肤品：增加护肤品广告曝光；其他品类：关注该品类的备货和陈列。取一条 |
| 二级品类销售额下降最多（下降 ≥ 10% 且减少金额最大） | 提示检查是否缺货或需要安排活动 |

上期不完整时不比较变化，只按占比判断。

## 6. 影响评估

| 方面 | 影响 |
| --- | --- |
| 数据库 | 无结构变更、无迁移 |
| 金额口径 | POS 明细单价为标价，订单另有整单折扣（开发库某一周明细标价合计约比实收高 27%）。销售额、客单价、每日趋势按订单实收；品类、人群、商品金额按标价，只用于比较占比和增减，页面注明 |
| 接口 | `GET /management/market-insights` 增加概览、趋势、品类占比、人群、热力图、商品榜、经营重点等字段；原字段保留，市场分析首页"本期要点"继续使用 |
| 统计区间 | 原"近 7 天 / 30 天 / 91 天"改为截至昨天（或数据截止日）的完整天数；突然热销、品类升降随之更准确 |
| 隐私 | 不使用顾客个人信息；POS 订单不含顾客资料 |
| POS、库存 | 只读，不影响 |
| 上线 | 无需数据库迁移，随代码更新生效 |
