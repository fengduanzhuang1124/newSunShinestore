# 需求变更单：手机端库存作业操作修复

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-016 |
| 关联需求 | 库存作业端（入库、库存管理、账户设置） |
| 状态 | 开发完成（待门店电脑更新，无需数据库迁移） |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈（手机截图） | 手机上"账户与设置"看不到、点不到退出登录 |
| 客户反馈 | 点货清单整理好后，"确认整单入库"按钮很难点到 |
| 客户反馈 | 不同员工同时点货有两张入库单时，完成和下载时提示要选择入库单，但页面没有可选择的地方 |
| 客户反馈（手机截图） | 库存台账、库存盘点的搜索在电脑上按回车可以，手机上没有搜索按钮，只有清除和相机扫码，搜索不了；盘点页显示"当前仓库没有可盘点库存" |

## 2. 原因

| 编号 | 原因 |
| --- | --- |
| C1 | 账户面板没有限制高度，也不能滚动，内容超过手机屏幕时底部的退出按钮被挤出屏幕 |
| C2 | 确认按钮放在点货清单表格最下方，清单长时要滑到底，且贴近底部导航栏 |
| C3 | "完成我的入库单"只会找本人打开的入库单；本人没有、仓库里又有两张时，系统无法判断要完成哪张，页面也没有按单操作的按钮 |
| C4 | 搜索框不在表单内，手机键盘只显示"换行"；台账的"查询"在输入中文拼音时一直是灰色；盘点页没有搜索按钮，库存读取失败或读取中也显示"没有可盘点库存" |

## 3. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 账户面板可滚动 | 面板最高为屏幕高度，超出部分在面板内滚动，退出按钮始终可以到达 |
| F2 | 确认入库按钮上移 | "确认整单入库"放到点货清单标题处，加入商品后不用滑到底就能点 |
| F3 | 按单完成与导出 | 每张"点货中"的入库单上增加"完成这张入库单"和"导出这张"；原"完成我的入库单"保留 |
| F4 | 手机搜索 | 台账、盘点搜索框放入表单，手机键盘显示"搜索"键；台账"查询"按钮随时可点；盘点页增加"搜索"按钮 |
| F5 | 盘点页状态 | 读取中显示"正在读取库存"，库存未读取时进入盘点页自动读取，读取失败显示原因 |

## 4. 权限

按单完成入库单沿用现有规则：有该仓库入库权限的账号可以完成本仓库"点货中"的入库单。
