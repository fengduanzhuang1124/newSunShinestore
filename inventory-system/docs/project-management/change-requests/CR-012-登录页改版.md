## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户提供参考图 | 登录页改为参考图的布局：左侧大标题、一行说明、三个带简约图标的功能点，中间主视觉，右侧玻璃登录卡（密码登录 / 验证码登录、记住我、忘记密码、立即登录、立即注册） |
| 客户提供参考图 | 主视觉为一颗透明鱼油胶囊转动，油滴落入金黄色"油海"，风格与参考的鱼油胶囊图一致 |
| 客户查看第一版后提出 | 金黄色配色不对，改回以深色为主的简约科技感，配色参考深底薄荷绿发光的磨砂玻璃风格；切换按钮改为简笔笑脸；主视觉改为鱼油软胶囊，Omega-3、DHA、EPA 三种成分围绕胶囊循环；增加粒子呼吸感 |
| 客户查看第二版后提出 | 薄荷绿配色仍不对，改为参考图的深蓝黑底配青、蓝、紫玻璃光；修改样式时保持规范，不叠加覆盖样式 |
| 客户查看第三版后提出 | 中间使用客户提供的鱼油胶囊图；三种成分改为上下环绕；文字配色调整；整个界面加可闪动的边框，标志放在边框内；界面不要过黑，要有通透、略微凸起的质感和呼吸感；浅色主题沿用改版前登录页的浅色 |
| 客户查看第四版后提出 | 边框缩小，居中显示在屏幕中部，保持玻璃质感；浅色改为嫩粉与淡紫渐变（参考配色 #FCAEC1、#FCD1DB、#B7A8D6、#ADD9F3）；标题文字立体，"阳光特产"与"再次伟大 / 一站式澳新好物专家"颜色区分；三种成分旋转时呈现彼此连线的医疗科技感；深色在当前基础上按暗色设计要点优化（深灰分层背景、文字灰度分层、亮色只用于按钮和选中状态、卡片悬浮、点击光晕） |
| 客户查看第五版后提出 | 浅色太粉、不透明，改为透明玻璃质感；标题上半句白色、下半句紫色并带透明度；三种成分的环绕轨道倾斜，与鱼油交叉；鱼油缩小；登录面板参照参考图立体突出，浅色、深色都要有呼吸感 |
| 客户查看第六版后提出 | 笑脸按钮切换一次后再点无反应，需可来回切换；鱼油与三种成分比例缩小，不影响文字；登录框更透明，有一束光沿组件经过；质感参考"磨砂玻璃 + 厚光泽边 + 边缘光 + 柔和投影"的海报风格 |
| 客户确认 | 左上角保留阳光特产标志；标题"让阳光特产再次伟大"，可点按钮切换为"阳光特产一站式澳新好物专家"；三个功能点为库存管理、管理端平台、AI 智能助手；配色加透明度（第一版金色系、第二版薄荷绿均已按客户意见改为深蓝黑底配青蓝紫）；右侧标题"欢迎登录阳光特产"；页面有 1–3 秒的呼吸感 |
| 客户确认 | 目前只使用已有的两个员工账号；验证码登录和注册只做界面展示，暂不开放 |

| 页面 | 浅色玻璃卡片，左侧表单，右侧粉蓝胶囊插画 |

## 3. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 整体布局 | 深色背景为深灰分层渐变（不用纯黑），叠加蓝紫柔光；整个页面内容放在屏幕中部一块居中、宽度不超过 1240 像素、略微凸起的半透明厚玻璃面板内（面板稍向观看者倾斜、带玻璃厚边，缓慢上下浮动，下方地面有呼吸光晕；手机端不倾斜），边框有一段光沿四周循环流动并呼吸发光，阳光特产标志和主题切换都在边框内；登录卡为磨砂玻璃，登录按钮为青到淡紫渐变；标题为立体字（多层投影），上半句（"让阳光特产" / "阳光特产"）为半透明白色，下半句（"再次伟大" / "一站式澳新好物专家"）为半透明紫色；文字按白 / 灰白 / 暗灰三级区分；登录按钮按下后有光晕扩散；左侧标题、说明和三个功能点，中间鱼油主视觉，右侧登录卡。手机端依次为标志、标题、主视觉、登录卡，功能点隐藏 |
| F2 | 标题切换（修复：切换为长标语后，按钮落在中间主视觉区域上方被其遮挡导致无法再点；主视觉改为不接收点击，并以真实鼠标点击连续验证四次来回切换） | 默认"让阳光特产 / 再次伟大"；点标题旁的简笔笑脸按钮（缓慢呼吸发光，切换后眨眼）换为"阳光特产 / 一站式澳新好物专家"，再点换回，文字淡入淡出 |
| F3 | 主视觉 | 客户提供的鱼油胶囊图（已去背景、去掉图上文字和倒影，存为 `public/login-fish-oil.webp`）缓慢浮动；Omega-3、DHA、EPA 三个金色光球沿一条与胶囊交叉的倾斜轨道环绕循环（转到后方时变小变暗、被胶囊遮住），三个光球之间以发光线相连成三角（靠前的连线显示在胶囊之上），光球带闪烁星光，并与胶囊之间有虚线光连接；底部光束汇聚到下方光圈，光圈泛起涟漪，背景同心圆与漂浮粒子明暗呼吸；系统"减少动态效果"时静止显示 |
| F4 | 呼吸感 | 登录卡边框光、登录按钮光、笑脸按钮、功能图标、胶囊边缘、粒子和背景光晕分别以约 2–4 秒节奏明暗变化 |
| F5 | 密码登录 | 沿用现有登录接口和账号，不改后端；密码可点眼睛图标显示/隐藏 |
| F6 | 记住我 | 勾选后在本机记住账号名（不保存密码），下次自动填入；取消勾选即清除 |
| F7 | 验证码登录、注册、忘记密码 | 只做界面：验证码登录页签显示"暂未开放，请使用账号密码登录"，输入框和获取验证码按钮不可用；"立即注册""忘记密码"提示"请联系管理员开通账号 / 重置密码"。不发送任何短信，不创建账号 |
| F8 | 主题 | 保留浅色 / 深色切换；浅色主题为淡粉、淡紫、浅蓝的柔和底色，透明玻璃面板（白色约 16–34% 透明度），淡紫圆角按钮和圆角输入框，粉紫蓝流光边框；所有颜色由一组变量控制，浅色主题只替换变量值 |
