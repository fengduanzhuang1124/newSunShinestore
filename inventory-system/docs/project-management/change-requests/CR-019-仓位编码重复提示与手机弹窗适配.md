# 需求变更单：仓位编码重复提示与手机弹窗适配

| 项目 | 内容 |
| --- | --- |
| 变更编号 | CR-019 |
| 关联需求 | CR-008（仓位）、CR-017（按品牌建仓位） |
| 状态 | 开发完成（待门店电脑更新，无需数据库迁移） |
| 日期 | 2026-11-09 |

## 1. 变更来源

| 渠道 | 内容摘要 |
| --- | --- |
| 客户反馈（手机截图） | 新增仓位（编码"地柜"、名称"Trilogy 货架"）点"创建仓位"不成功，询问是否创建次数太多 |
| 客户补充 | 一层货架可能放 2 个品牌，同一位置不要严格禁止 |
| 客户反馈 | 手机上新增仓位弹窗适配不好，超出屏幕、页面乱跳 |
| 正式库只读核查 | 编码"地柜"已被 10 号仓位"Manuka Doctor 货架"使用；同一仓库内仓位编码唯一，之后 8 次创建均被数据库拒绝（仓位编号 11–18 空缺）。没有次数限制 |

## 2. 原因

| 编号 | 原因 |
| --- | --- |
| C1 | 编码重复时接口返回通用错误，没有说明是编码重复 |
| C2 | 错误提示显示在弹窗后面的页面上，弹窗内看不到任何反馈 |
| C3 | 库存页面主区域带有背景模糊效果，导致弹窗按页面区域而不是屏幕定位，页面滚动后弹窗位置偏移、看起来乱跳；弹窗没有限制高度、不能在内部滚动，6 个输入框单列排列超出屏幕；输入框字号小于 16px，iPhone 点击输入框时自动放大页面，造成跳动 |

## 3. 变更内容

| 编号 | 内容 | 规则 |
| --- | --- | --- |
| F1 | 编码重复即时处理 | 输入的编码与已有仓位相同（不分大小写）时，弹窗内提示该编码已是哪个仓位，并给出两个按钮：从"按品牌放置"新建时可"放到该仓位，和现有品牌同一位置"（一个仓位可放多个品牌，不再新建）；或"单独建一格"，自动改用第一个未被占用的下级编码（如 地柜-2）。同一编码不能建第二个仓位 |
| F2 | 接口明确报错 | 新增、修改仓位编码重复时返回"仓位编码 X 已被使用，请换一个编码"，不再返回通用错误 |
| F3 | 弹窗内显示错误 | 保存失败的原因显示在弹窗内按钮上方 |
| F4 | 手机弹窗适配 | 手机上弹窗从底部弹出，最高为屏幕 92%，内容在弹窗内滚动；编码、名称占整行，区域、通道、货架、层级两列排列；输入框字号 16px，避免 iPhone 自动放大 |

## 4. 使用说明

同一个物理位置（如地柜）放多个品牌时，只需要一个仓位：在"按品牌放置"选品牌（如 Trilogy），目标仓位选"地柜"，一次放入即可，不需要再新建同名编码的仓位。
