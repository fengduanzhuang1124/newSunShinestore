## 列入规则

| 类别 | 规则 | 优先级 |
| --- | --- | --- |
| 10-20 入库单叠加 | 商品同时出现在 RK-20261020 与 10-08～10-13 的录入中；若 10-20 为重新点数则被重复计数 | 高 |

| POS 库存不足 | POS 销售明细有未扣完的数量（`INSUFFICIENT_INVENTORY`） | 高 |
| 多次入库录入 | 不同日期或单据录入 2 次及以上 | 中 |

| POS 未对应 | 有库存但没有 ACTIVE 的 POS 商品映射，卖出不会扣库存 | 低 |
| 已过期 | 过期批次仍有数量 | 低 |
