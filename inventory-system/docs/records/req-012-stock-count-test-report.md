| 导入 | `apps/api/scripts/import-stock-count-task.ts`：校验清单（商品存在且启用、不重复、任务编号唯一），默认预演；`--execute --backup=<备份>` 时单一事务写入任务、明细与审计 |
| 接口 | `GET /inventory/count-tasks/current`（任务与全部明细及当前批次）、`GET /inventory/count-tasks/current/summary`（仅进度）、`POST /inventory/count-tasks/:taskId/items`（临时加入商品）、`POST /inventory/count-tasks/:taskId/items/:itemId/confirm`（确认）；均要求盘点权限 + 门店管理员 |
| 确认规则 | 按到期日与精度对齐批次（`stock-count-plan.ts`）：调整已有批次、未点到的批次归零、新到期日新建批次；版本校验防并发；`STOCKTAKE_GAIN/LOSS` 流水（`reference_type = STOCK_COUNT`）；审计记录调整前后批次；`requestId` 防重复提交；最后一个商品确认后任务自动完成 |
| POS 覆盖 | 扣库计划、复核补扣中，订单时间早于该商品最近一次盘点确认的明细不再扣减，标记 `COVERED_BY_STOCKTAKE`，不计入复核问题与缺口；确认时把该商品此前“库存不足”的复核明细一并标记为已覆盖 |
| 前端 | 新组件 `src/stockcount/StockCountTasks.vue`：进度、高/中/低/已完成分组、搜索与扫码、底部弹出核对面板（改数量、改到期日、增删批次、差异提示）、确认后自动打开下一个；首页（管理员）显示“盘点任务进行中”提示卡，“更多”菜单增加入口 |
