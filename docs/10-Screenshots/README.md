# 10 — Screenshots

本目录保存可验证的 Before/After 界面截图。

## 规则

- 只有真实页面或运行结果发生变化时才保存截图；
- 文件名使用 `YYYY-MM-DD-module-before.png` 和 `YYYY-MM-DD-module-after.png`；
- 截图说明应关联开发日志、Issue 和测试报告；
- 必须遮盖客户姓名、电话、地址、订单号、支付信息、token 和密钥；
- 纯文档、数据库设计或无 UI 的变更标记为“不适用”，不创建虚假截图；
- 同一功能优先使用相同尺寸和相同测试数据截图。

本次需求与设计基线没有 UI 变化，因此没有 Before/After 图片。
