# 项目现状与开发路线

更新日期：2026-07-30

## 当前主线

第一优先级已经确认为独立的 Sunshine Inventory Management System 外挂进销存系统。

当前完成到：

- 第一阶段业务规则初步确认；
- 多门店、多仓库、多条码和多到期日期设计初稿；
- 权限矩阵、库存流水类型和 API 初稿；
- Mac 开发环境检查。
- `inventory-system/` pnpm workspace；
- NestJS API 与健康检查；
- Vue 3 管理端地基页面；
- Prisma 7 Schema 和初始 MySQL migration；
- 门店商品中间表 `store_products`；
- 基础类型检查、Schema 契约测试和构建。
- Node.js 24 LTS 与 Docker Desktop 开发环境；
- MySQL 8.4.11 本地容器及初始 migration 实库验证。

尚未开始：

- 扫码页面；
- 登录与实际权限服务；
- 库存写入事务；
- 扫码枪硬件测试。

当前环境：系统 Node.js 24.18.1、npm 11.16.0 和 Docker Desktop 29.6.2 可用；MySQL 8.4.11 容器健康运行于本机端口3307。

## 状态说明

- `已有基础`：代码中存在主要实现，但不代表已经通过完整测试。
- `部分完成`：页面或 API 已存在，仍有模拟数据、契约或业务缺口。
- `未开始`：未发现可验证实现。
- `延后`：核心交易闭环稳定后再安排。

## 分阶段路线

### 阶段 0：需求、设计和开发环境

- 确认门店、仓库、商品、条码、日期和员工流程；
- 完成01–06号文档；
- 安装 Node.js、Docker 和开发工具；
- 确认第一门店/仓库名称及剩余业务待定项。

### 阶段 1：外挂库存数据和 API

- 创建 NestJS、Vue 3 和 Prisma 项目；
- 建立多门店、多仓库、商品、多条码和到期日期；
- 建立库存流水、汇总、权限和审计；
- 建立 migration、事务和自动测试。

### 阶段 2：扫码库存 MVP

- 扫码查询和未知商品登记；
- 手工/Excel/扫码初始库存；
- 入库、手工出库、调拨和盘点；
- 临期提醒和日期查询；
- 门店电脑和平板试运行。

### 阶段 3：试运行和 v0.1.0

- 门店 Mini PC/局域网部署；
- 员工培训和 SOP；
- 备份、恢复和监控；
- 试运行修正并发布 v0.1.0。

### 阶段 4：统一管理和线上销售

- 统一商品、订单、促销和物流管理；
- 英文网页销售端和微信小程序复用统一 API；
- 微信人工订单录入。

### 阶段 5：外部整合与 AI

- POS CSV/API 和销售对账；
- 销售大屏；
- FAQ 数据治理和 AI 员工辅助客服；
- 成本、隐私和质量评估。
